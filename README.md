## 📶 1. وضع عدم الاتصال والتطبيق التقدمي (Offline Mode & PWA)

البنية التحتية للتطبيق مبنية على مبدأ واحد: **كتاب الله متاح دايمًا، حتى بدون نت.**

| الميزة | التفاصيل |
| :--- | :--- |
| 📲 **تطبيق ويب تقدمي (PWA)** | تثبيت على الشاشة الرئيسية للهاتف أو الكمبيوتر بضغطة زر واحدة، بدون المرور على متجر تطبيقات |
| ⚡ **تخزين مؤقت ذكي (Caching)** | تكامل متقدم مع `Cache API` و `Service Workers` لتخزين صفحات القرآن والتفاسير وفهرس الأجزاء، واستدعائها فورًا عند انقطاع الاتصال |
| 🎧 **تحميل السور للاستماع** | تحميل ملفات MP3 لسورة كاملة بصوت القارئ المفضل، مع مؤشر تقدّم دقيق (%)، للاستماع لاحقًا بدون استهلاك بيانات |
| 💾 **حفظ بيانات المستخدم** | الإعدادات، آخر صفحة قراءة، العلامات المرجعية، وتفضيلات الوضع الليلي واللغة — كلها محفوظة محليًا عبر `LocalStorage` |

## 📖 2. تجربة القرآن الكريم (القراءة والاستماع)

- **محاكاة المصحف العثماني** — تقسيم الآيات وتوزيعها على الصفحات مطابق تمامًا للمصحف الورقي المطبوع، مش مجرد نص متدفق.
- **التقليب باللمس (Swipe to Turn)** — إيماءات سحب طبيعية لتقليب الصفحات على شاشات اللمس.
- **مشغل صوتي متقدم**:
  - 🎙️ دعم **11 قارئًا** من كبار القراء (العفاسي، عبد الباسط، الحصري، السديس، الشريم، المعيقلي، وغيرهم).
  - ✨ **تتبع القراءة الحي** — تظليل الآية التي يتم تلاوتها لحظيًا لمتابعة بصرية سلسة.
  - 🔄 **تقليب تلقائي للصفحة** — الصفحة تتقلب وحدها بمجرد ما القارئ يخلص آخر آية فيها، من غير أي تدخل من المستخدم.
  - 🎯 **تشغيل مزدوج** — سورة كاملة متسلسلة، أو آية واحدة بس، حسب الحاجة.
- **إعدادات خط ديناميكية** — تحكم كامل في حجم خط المصحف (16px إلى 60px) ليتناسب مع أي شاشة أو أي عين.

## 🎨 3. محرك كارت الآية والمشاركة (Story Card Engine)

نظام مبني بالكامل من الصفر بـ `HTML5 Canvas` — مش قص شاشة، رسم حقيقي بدقة HD (1080×1920) جاهز لحالات إنستجرام وفيسبوك:

- 🕌 **تصميم إسلامي فاخر** — خلفية "أونيكس وذهب" متدرجة، توهجات ذهبية دافئة، نقش نجمي ثماني خفيف، وإطار محراب مقوس بزوايا أندلسية.
- ✏️ **رسم متجهي بدقة بكسل** — هلال ونجمة مرسومين رياضيًا بإحداثيات Canvas، بدون أي تشويه عند التكبير.
- 📐 **خوارزمية تحجيم ذكية للنص** — تقرأ طول الآية وتختبر أحجام خطوط وارتفاعات أسطر مختلفة تلقائيًا لحد ما توصل لأفضل توزيع يملأ الكارت بتناسق، مهما كان طول الآية.
- 🏷️ **شارة معلومات متمركزة** — اسم السورة، رقم الآية، واسم التطبيق في شارة سفلية أنيقة.
- 📤 **3 طرق مشاركة** — تحميل الكارت كصورة PNG، مشاركة مباشرة عبر `Web Share API`، أو نسخ نص الآية بتنسيق منسق جاهز للّصق.

## 🧠 4. التفاعل، التحفيظ، والتفاسير

- **قائمة آية ذكية (Smart Popover)** — قائمة عائمة تظهر عند النقر على أي آية، وموقعها بيتحسب برمجيًا في كل مرة عشان تفضل جوه حدود الشاشة مهما كان مكان الآية.
- **وضع التحفيظ** — إخفاء كل آيات الصفحة بتأثير ضبابي، وإظهار الآية المطلوبة بس عند النقر عليها — أداة مراجعة حقيقية مش مجرد إخفاء نص.
- **مكتبة تفاسير ديناميكية** — تبديل لحظي بين 3 تفاسير (الميسر، الجلالين، القرطبي) بتنسيق مريح للعين.
- **علامات مرجعية (Bookmarks)** — حفظ الآيات في قائمة جانبية أنيقة، مع اسم السورة ورقم الصفحة، وعدّاد مباشر في شارة علوية.
- **فهرس أجزاء تفصيلي** — عرض دقيق لكل سورة داخل كل جزء، محددة بآية البداية والنهاية بالظبط.

<br/>

## 📻 5. إذاعات القرآن الكريم (Live Radio)

- **بث مباشر** — اتصال بـ API لجلب مئات الإذاعات، مع بحث لحظي للتصفية الفورية.
- **تصنيف وتنظيم** — تقسيم أبجدي للوصول السريع، وتبويب خاص بـ"الإذاعات المميزة" (فتاوى، تكبيرات، أطفال، رمضان).
- **مشغل راديو احترافي**:
  - معالجة متقدمة لأخطاء البث (`AbortError`) وتحويل الروابط غير الآمنة من `http` لـ `https` تلقائيًا لمنع حظر المتصفح.
  - مشغل عائم بتأثير نبض بصري (Pulse) يعرض الإذاعة الحالية.
  - منع تداخل صوتي مضمون بين مشغل القرآن والراديو.

## ⚙️ 7. البنية التحتية وتجربة المستخدم (UI/UX)

- **تحكم ذكي بزر الرجوع** — خوارزمية مبنية على `History API` وتعديل `URL Hash` (`#dialog`) تضمن إن زر رجوع الهاتف بيقفل القوائم والنوافذ المنبثقة أولاً، بدل ما يطرد المستخدم من التطبيق كله.
- **شريط تنقل سفلي احترافي** — مصمم خصيصًا للموبايل بزرار مركزي بارز ونابض للقرآن.
- **مظهر داكن وفاتح** — تكامل ألوان كامل (أبيض/ذهبي للنهاري، أونيكس/ذهبي فاتح لليلي).
- **دعم لغتين كامل (i18n)** — عربي وإنجليزي مع تبديل جذري لاتجاه الواجهة (RTL/LTR)، مش مجرد ترجمة نص.
- **نظام تنبيهات (Toast)** — رسائل بصرية متحركة تفيد المستخدم بحالة النسخ، التحميل، أو انقطاع الاتصال لحظيًا.

## 🔌 واجهات برمجة التطبيقات المستخدمة (APIs Used)

- [AlQuran Cloud API](https://alquran.cloud/api) — نصوص القرآن، التفاسير، وتفاصيل الأجزاء.
