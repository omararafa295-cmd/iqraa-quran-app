## ✨ عن اقرأ

**اقرأ** ليس مجرد واجهة لعرض نص القرآن. الفكرة الأساسية هي بناء تجربة استخدام عملية ومريحة تجمع الأدوات التي يحتاجها المستخدم في مكان واحد، مع اهتمام خاص بالموبايل، العمل بدون إنترنت، استمرارية القراءة والاستماع، وسهولة الوصول للمحتوى.

التطبيق مصمم بحيث يظل القرآن محور التجربة، بينما الأدوات الأخرى مثل الختمة، الأذكار، الأحاديث، القبلة، المواقيت، الراديو والتقويم تعمل حوله بدون تعقيد أو تنقل زائد.

## 🚀 أبرز المميزات

### 📖 تجربة القرآن الكريم

- عرض السور والأجزاء والتنقل بينها بسهولة.
- تخطيط صفحات قريب من تجربة المصحف الورقي بدل عرض النص كسطور غير مترابطة.
- دعم السحب باللمس للتنقل بين الصفحات على الموبايل.
- حفظ آخر موضع قراءة والعودة إليه لاحقًا.
- الانتقال مباشرة إلى صفحة أو آية محددة من نتائج البحث والعلامات المرجعية.
- تحكم ديناميكي في حجم خط القرآن.
- دعم كامل للوضعين الفاتح والداكن.

### 🔎 البحث الذكي في القرآن

- البحث داخل أسماء السور أو داخل نص القرآن كاملًا.
- معالجة النص العربي قبل البحث لتقليل تأثير التشكيل واختلاف أشكال الحروف.
- عرض نتائج البحث مع السورة والآية وموقعها.
- إمكانية القفز مباشرة من نتيجة البحث إلى موضع الآية داخل المصحف.
- تخزين بيانات البحث محليًا لاستخدام أسرع وتقليل الطلبات المتكررة.

### 🎧 الاستماع والتلاوات

- دعم **14 قارئًا** داخل مكتبة الصوتيات.
- تشغيل القرآن آية بآية مع استمرار تلقائي للآية التالية.
- تظليل الآية الجاري تشغيلها لتسهيل المتابعة البصرية.
- انتقال تلقائي بين الصفحات أثناء الاستماع عندما ينتهي تشغيل الصفحة الحالية.
- مشغل صوت عائم يظل متاحًا أثناء التنقل داخل التطبيق.
- منع التعارض بين تشغيل القرآن والراديو.

### 📥 مدير تحميل الصوتيات

مدير صوتيات مستقل مصمم للاستماع بدون إنترنت، وليس مجرد زر تحميل سورة.

- تحميل القرآن كاملًا بصوت القارئ المختار.
- تحميل أكثر من قارئ معًا بحد أقصى مناسب للحفاظ على استقرار الاتصال.
- **Pause / Resume** بدون إعادة الملفات المكتملة من البداية.
- استمرار التحميل أثناء التنقل بين صفحات التطبيق طالما التطبيق مفتوح.
- عرض نسبة التقدم وعدد الآيات المكتملة.
- عرض سرعة التحميل الحالية.
- تقدير الحجم الذي تم تحميله والحجم الكلي المتوقع.
- تقدير الوقت المتبقي للتحميل.
- عرض المساحة التقريبية المتاحة للتطبيق على الجهاز.
- حفظ حالة التحميل والـ manifest محليًا لسهولة الاستكمال.
- حذف تحميل قارئ كامل أو التحميل الجزئي.
- مزامنة تلقائية بين تحميل القرآن الكامل وزر تحميل السورة: بمجرد اكتمال جميع آيات سورة لقارئ معين يتم اعتبار السورة متاحة Offline فورًا.
- تخزين ملفات الصوت داخل `Cache API` للاستماع بدون إنترنت.

### 🔖 العلامات المرجعية

- حفظ أي آية كعلامة مرجعية.
- Drawer مستقل للوصول السريع للعلامات.
- عرض اسم السورة ورقم الآية ورقم الصفحة.
- الانتقال للآية مباشرة عند الضغط على العلامة.
- عداد مباشر للعلامات في الشريط العلوي.

### 🎨 كارت الآية والمشاركة

- توليد كروت آيات باستخدام `HTML5 Canvas` بدل الاعتماد على Screenshot.
- مقاس عالي الجودة مناسب للمشاركة على Story.
- دعم اختيار آية واحدة أو مجموعة آيات ضمن حدود مناسبة للتصميم.
- تحجيم تلقائي للنص حسب طول المحتوى.
- تصميم بصري إسلامي بإطار وزخارف وهوية ذهبية.
- تضمين اسم السورة وأرقام الآيات داخل الكارت.
- تحميل الكارت كصورة PNG.
- المشاركة باستخدام `Web Share API` على الأجهزة المدعومة.
- نسخ نص الآية للمشاركة السريعة.

### 🧠 الحفظ والتسميع

- قسم مخصص للتسميع والمراجعة.
- وضع يساعد على إخفاء الآيات وإظهارها عند الحاجة للمراجعة.
- أدوات تفاعلية تساعد المستخدم على مراجعة ما حفظه بدل الاكتفاء بالقراءة فقط.

### 📚 التفاسير

- عرض التفسير مباشرة من قائمة الآية.
- دعم أكثر من مصدر تفسير داخل نفس تجربة القراءة.
- إمكانية التبديل بين التفاسير بدون مغادرة السورة.

### 🎯 خطة الختمة

- إنشاء خطة ختمة بناءً على عدد الأيام المطلوب.
- متابعة التقدم اليومي داخل الخطة.
- حفظ الخطة محليًا حتى بعد إغلاق التطبيق.
- إشعارات تذكيرية مرتبطة بخطة الختمة عند توفر صلاحية الإشعارات.
- إمكانية حذف الخطة وإعادة إنشائها.

### 📜 الأحاديث النبوية

- قسم مستقل لقراءة وتصفح الأحاديث.
- واجهة متوافقة مع تصميم التطبيق والوضع الليلي.
- وصول مباشر من شريط التنقل السفلي.

### 🌅 الأذكار

- قسم منظم للأذكار اليومية.
- تجربة مناسبة للموبايل والقراءة المتكررة.
- دعم الوضع الفاتح والداكن واللغتين داخل الواجهة العامة.

### 📻 إذاعات القرآن الكريم

- بث إذاعات القرآن مباشرة عبر الإنترنت.
- البحث والتصفية داخل قائمة الإذاعات.
- مشغل عائم للإذاعة الحالية.
- التعامل مع مشاكل روابط البث وMixed Content عند الإمكان.
- منع تشغيل الراديو والقرآن فوق بعضهما في نفس الوقت.

### 🕋 مواقيت الصلاة

- جلب المواقيت حسب الموقع.
- البحث عن المدن مع اقتراحات للنتائج.
- حفظ المدينة والدولة محليًا لتقليل خطوات الاستخدام لاحقًا.
- واجهة متجاوبة تعرض مواقيت اليوم بشكل واضح.

### 🧭 اتجاه القبلة

- حساب اتجاه القبلة حسب الموقع الجغرافي.
- الاستفادة من مستشعرات الجهاز عند توفر الصلاحيات والدعم.
- معالجة خاصة لتجربة iPhone والأجهزة التي تتطلب إذنًا صريحًا للوصول لمستشعر الاتجاه.

### 📅 التقويم الهجري والميلادي

- تقويم شهري يجمع الميلادي والهجري في نفس الواجهة.
- عرض الرقم الميلادي والهجري لكل يوم بدون الحاجة للتبديل بين تقويمين.
- التنقل بين الشهور بسهولة.
- عرض تفاصيل اليوم المحدد بالهجري والميلادي.
- إظهار المناسبات الإسلامية المرتبطة باليوم عند توفرها.
- تخزين بيانات الشهر مؤقتًا لتحسين السرعة وتقليل استدعاءات الـ API.
- Fallback محلي باستخدام `Intl.DateTimeFormat` إذا تعذر الاتصال بالخدمة الخارجية.
- دعم تقويم Umm al-Qura عند توفره في المتصفح.

## 📱 تجربة PWA و Offline

اقرأ مصمم ليعمل كتطبيق حقيقي على الهاتف وليس كموقع تقليدي فقط.

| الميزة | التفاصيل |
| :--- | :--- |
| 📲 **التثبيت** | تثبيت التطبيق على الشاشة الرئيسية على Android وDesktop مع إرشادات مخصصة لتثبيته على iPhone عبر Safari |
| ⚡ **Service Worker** | تخزين الموارد الأساسية وتشغيل أجزاء كبيرة من التطبيق بدون إنترنت |
| 🎧 **Offline Audio** | حفظ تلاوات الآيات والسور والقرآن الكامل داخل Cache API |
| 📖 **Offline Quran Data** | تخزين بيانات السور والقرآن وبيانات البحث محليًا عند الحاجة |
| 💾 **Persistent State** | حفظ آخر قراءة والختمة والإعدادات والعلامات المرجعية وحالات التحميل عبر LocalStorage |
| 🔄 **Resume Downloads** | استكمال تحميل الصوتيات من الملفات الناقصة بدل بدء التحميل من الصفر |

> استمرار التحميل مضمون أثناء التنقل داخل التطبيق طالما صفحة التطبيق نفسها ما زالت فعالة. المتصفح قد يوقف الشبكة إذا تم إغلاق التبويب أو تجميد التطبيق بالكامل في الخلفية، لذلك يتم حفظ التقدم لإتاحة الاستكمال عند العودة.

## 🧩 تجربة الواجهة والاستخدام

- تصميم **Mobile-first** ومتجاوب مع الهاتف والتابلت والكمبيوتر.
- دعم عربي وإنجليزي مع إدارة اتجاه `RTL / LTR` حسب اللغة.
- Dark Mode محفوظ محليًا.
- Drawers مستقلة للعلامات المرجعية والصوتيات والتقويم.
- قفل Scroll الصفحة الخلفية أثناء فتح الـ Drawers.
- التحكم في زر Back الخاص بالموبايل باستخدام `History API` و`#dialog` بحيث يغلق الـ Drawer قبل مغادرة الصفحة.
- دعم تثبيت PWA على iOS بتعليمات مخصصة للمستخدم.
- مكونات Loading وError وOffline states بدل ترك الواجهة بدون Feedback.
- تصميم موحد بالألوان الذهبية عبر مختلف أقسام التطبيق.

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
| :--- | :--- |
| **React 19** | بناء واجهات ومكونات التطبيق |
| **React Router** | التنقل بين أقسام التطبيق والسور والأجزاء |

| **LocalStorage** | حفظ الإعدادات والختمة وحالة القراءة والتحميلات |

| **History API** | التحكم الذكي في زر الرجوع والـ Drawers |
| **Web Storage API** | تقدير مساحة التخزين المتاحة للتحميلات |

## 🔌 واجهات ومصادر البيانات

- [AlQuran Cloud API](https://alquran.cloud/api) — بيانات القرآن والسور والأجزاء وبعض مصادر التفسير والصوت.
- [EveryAyah](https://everyayah.com) — ملفات تلاوة آية بآية لعدد من القراء.
- [MP3Quran](https://mp3quran.net/) — مصادر إذاعات القرآن والبث المباشر.
- [AlAdhan API](https://aladhan.com/prayer-times-api) — مواقيت الصلاة والتقويم والتحويل بين الميلادي والهجري.
- مصادر صوت إضافية تستخدم لبعض القراء عندما لا يتوفر ملف مناسب من المصدر الرئيسي.
